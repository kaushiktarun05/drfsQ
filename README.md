## 🧩 Overview

**drfsQ** is an all-in-one developer toolset designed for **extracting, decoding, and visualizing drone flight data** efficiently.
It integrates **data processing, spatial analysis, and interactive visualization** within a flexible architecture tailored for **forensic investigations, monitoring, and analysis**.

### Why drfsQ?

This project simplifies complex drone data workflows, enabling developers to seamlessly handle raw formats, generate interactive maps, and visualize 3D drone models.

**Core Features**

* 🛸 **Interactive Flight Path Visualization:** Generate dynamic maps to track drone routes in real-time or from stored data.
* 🚁 **DJI Data Extraction & Decoding:** Efficiently retrieve embedded files and interpret proprietary formats for comprehensive analysis.
* 🌐 **Web-Based Data Management:** Upload, process, and visualize drone data through an intuitive Flask interface.
* 🔍 **Modular Telemetry Parsing:** Extract key flight parameters, sensor data, and geospatial information with flexible modules.
* 🎥 **3D Drone Visualization:** View immersive drone models and spatial data within a web environment.
* ⚙️ **Serverless Deployment Support:** Easily deploy on platforms like Vercel for scalable, cloud-based workflows.

## ⚙️ Getting Started

### Prerequisites

This project requires the following dependencies:

* Programming Language: **Python 3.8+**
* Package Manager: **pip**

---

### Installation

**1. Clone the repository:**

```bash
git clone https://github.com/kaushiktarun05/drfsQ
```

**2. Navigate to the project directory:**

```bash
cd drfsQ
```

**3. Install the dependencies:**

```bash
pip install -r requirements.txt
```

---

### Usage

**Run the project with:**

```bash
python <entrypoint>.py
```

For example:

```bash
python app.py
```

Then open your browser at `http://localhost:5000`.

---

### Testing

drfsQ uses the **pytest** framework for testing.
Run the test suite with:

```bash
pytest
```
